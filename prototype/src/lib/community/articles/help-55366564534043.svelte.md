<h2>From the official source</h2>
<p>Q: What must a complete FedRAMP 20x Class A package include?</p>
<p>A: A complete FedRAMP 20x Class A package includes:</p>
<p>External Assessment Materials</p>
<p>Certification Package Overview (CPO)</p>
<p>Security Decision Record (SDR)</p>
<p>Sample schemas (referenced by applicable rules) Initial Incident Report (IEC-CSO-IIR) SHOULD Ongoing Incident Report (IEC-CSO-OIR) SHOULD Final Incident Report (IEC-CSO-FIR) MUST Historical VER Activity (VER-TFR-MRH) MAY - if Rule is included in SDR Ongoing Certification Report (CCM-OCR-AVL) MUST</p>
<p>Initial Incident Report (IEC-CSO-IIR) SHOULD</p>
<p>Ongoing Incident Report (IEC-CSO-OIR) SHOULD</p>
<p>Final Incident Report (IEC-CSO-FIR) MUST</p>
<p>Historical VER Activity (VER-TFR-MRH) MAY - if Rule is included in SDR</p>
<p>Ongoing Certification Report (CCM-OCR-AVL) MUST</p>
<p>Assessment Summary (in SDR) and Overall Summary of Assessment (CPO) - if optional IV&amp;V</p>
<p>Tips for a Smooth Process</p>
<p>Completeness</p>
<p>Human and machine-readable files present</p>
<p>ALL MUST and SHOULD rules included in SDR (even if not met)</p>
<p>MAY are extra credit, but if included will be FULLY reviewed</p>
<p>Accuracy</p>
<p>Use the JSON Schema Validator: https://www.fedramp.gov/schemas/validator/</p>
<p>If a rule/KSI is not fully implemented, mark as Partially Implemented - please and thanks</p>
<p>Review Experience</p>
<p>Easy to access and use Trust Center</p>
<p>Simple to find artifacts (direct links from SDR best!)</p>
